# Подготовка main к github

Текущая команда публикации и её проверки описаны в [publishing.md](publishing.md).
Ниже — состав материалов, исключаемых из публичной ветки.

1. Для продолжения разработки и сохранения всех текущих артефактов создается ветка dev, а main очищается от всего, что не относится напрямую к исследованию и пайплайну.
Файловый состав веток отличается; публикации связываются merge-коммитами с выборочным публичным деревом. Версия PDF с постфиксом `_uni` остаётся только в `dev`.

2. Из main убираются:
- Все из data, за исключением того, что использовалось напрямую в исследовании для возможности воспроизводимости результатов (в т.ч. отдельные experiments)
- docs/
- external/
- logs/
- memory_bank/
- results/figures
- term-paper/
- term-paper_2/
